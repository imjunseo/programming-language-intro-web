# 🌐 Programming Language Introduction (프로그래밍 언어 소개 웹사이트)

> **프로그래밍 언어의 역사와 발전 과정을 한눈에 탐색할 수 있는 웹 프로젝트**  
> 🔗 **Live Demo**: [웹사이트 방문하기](https://inquisitive-beijinho-eafc04.netlify.app)

---

## 📌 1. 프로젝트 개요 (Overview)
* **프로젝트명**: Programming language introduction
* **목적**: 기존에 학습한 다양한 프로그래밍 언어(C, HTML, JavaScript 등)의 역사와 발전 과정을 조사하고, 이를 웹 페이지 형태로 체계적으로 정리하여 언어에 대한 깊은 이해를 도모합니다.

---

## 🛠 2. 사용 기술 스택 (Tech Stack)
* **Frontend**: HTML5, CSS3, JavaScript
* **Deployment**: Netlify

## 🖥 3. 주요 기능 및 페이지 구조 (Features)
* **홈 (Main Page)**: 프로젝트 소개 및 주요 프로그래밍 언어 카테고리 안내
* **C 언어 소개 (`C.html`)**: C 언어의 역사, 특징 및 주요 활용 분야 정리
* **HTML / CSS 소개 (`html.html`)**: 마크업 언어 및 웹 스타일링 기초 개념 정리
* **JavaScript 소개 (`JavaScript.html`)**: 동적 웹 개발을 위한 자바스크립트 특징 안내

---

## 4. 소스와 배포

이 저장소는 팀 웹 프로젝트의 화면 구성과 회고를 기록합니다. 현재 기본 브랜치에는 README가 있으며, 위 Netlify 주소는 프로젝트에서 사용한 배포 링크입니다.

## 💡 5. 회고 및 개선 방향 (Retrospective)

### 🌿 당시 배운 점
* HTML/CSS/JavaScript의 기본 구조를 이해하고 팀원들과 분업하여 하나의 완성된 웹사이트를 구축하는 경험을 쌓았습니다.
* Netlify를 활용한 웹 배포 프로세스를 익혔습니다.

### 🔄 현재 시점에서 본 개선 포인트 (Troubleshooting & Improvement)
* **반응형 웹 디자인 적용**: 당시 작성된 스타일시트를 시만틱 태그(Semantic Tags) 기반으로 리팩토링하고, Flexbox/Grid 및 미디어 쿼리를 도입해 모바일 환경 응답성 보완 가능.
* **코드 구조화 및 컴포넌트화**: 중복되는 CSS 클래스 및 스크립트를 모듈화하여 유지보수성 향상 필요.
* **웹 접근성(Accessibility) 강화**: 이미지 태그의 `alt` 속성 보완 및 웹 표준 준수를 통한 검색엔진 최적화(SEO) 개선 가능.
